# הקמפוס 🎓 | TheCampus - רשת חברתית לימודית לסטודנטים

פרויקט סיום במסגרת הקורס **"סדנה בפיתוח אפליקציות לענן ולרשת" (20995)** האוניברסיטה הפתוחה – סמסטר 2026ב  

---

## 📌 אודות הפרויקט
**"הקמפוס"** היא פלטפורמה חברתית-אקדמית המיועדת לסטודנטים, המאפשרת חיבור בין לומדים לפי קורסים ומיקום גיאוגרפי.  
המערכת כוללת:
- **פורומים ופיד אישי:** השתתפות בפורומים של קורסים, העלאת פוסטים ותגובות מקוננות.
- **ניהול חומרי לימוד:** העלאה ושריון של קבצים (PDF, תמונות, סרטונים) ישירות למאגר החומרים של הקורס.
- **איתור שותפים ללמידה (Google Maps API):** מפה אינטראקטיבית לאיתור סטודנטים קרובים לפי רדיוס, קורסים משותפים, גיל ומגדר.
- **אבטחה וניהול משתמשים:** אימות סטודנטים, הרשאות גישה והגדרת פרופיל אישי.

---

## 🛠️ טכנולוגיות וארכיטקטורה
המערכת בנויה בארכיטקטורת **Serverless** מלאה המבוססת על שירותי הענן של Firebase ו-Google Cloud:

- **Frontend:** React (Vite), CSS, React Router DOM, @vis.gl/react-google-maps.
- **Backend & Cloud Infrastructure:**
  - **Firebase Authentication:** ניהול אימות ואישור משתמשים.
  - **Cloud Firestore:** בסיס נתונים NoSQL בזמן אמת לניהול המשתמשים, הפורומים, הפוסטים והתגובות.
  - **Firebase Storage:** אחסון ענן עבור קבצים וחומרי לימוד.
  - **Firebase Security Rules:** אבטחת מידע והרשאות גישה ברמת הענן.

---

## 🔒 אבטחת מידע ו-Firebase Rules
כללי האבטחה וההרשאות של בסיס הנתונים (Firestore) והאחסון (Storage) מוגדרים בענן של Firebase.  
לצורך עיון ובדיקה, העתק של החוקים שנכתבו והוגדרו בענן נשמר בקבצי הפרויקט:
- `firestore.rules` – חוקי הקריאה/כתיבה וההרשאות עבור מסמכי ה-Firestore.
- `storage.rules` – חוקי הגישה והעלאת קבצים עבור Firebase Storage.

## 🚀 הוראות הפעלה והרצה מקומית

### דרישות קדם:
- התקנת **Node.js** (גרסה 18 ומעלה מומלצת).

### שלבי ההרצה:

1. **ניווט לתיקיית הפרונטאנד:**
   פתחו את הטרמינל בתיקייה הראשית של הפרויקט והיכנסו לתיקיית ה-`client`:
   ```bash
   cd client
   ```
2. **התקנת התלויות (Dependencies):**
    ```bash
    npm install
    ```
3. **הרצת שרת הפיתוח:**
    ```bash
    npm run dev
    ```
    לאחר מכן יופיע קישור בטרמינל (בדרך כלל http://localhost:5173) – פתחו אותו בדפדפן.
